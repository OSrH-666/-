# 数据库设计文档目录

本目录包含大学生社团学生会信息管理系统的完整数据库设计文档。

## 文件结构

```
database-design/
├── README.md          # 本文件，目录说明
├── er-diagram.md      # ER图设计
├── schema.md          # 建表SQL说明
├── fields.md          # 字段详细说明
└── initialization.md  # 数据初始化说明
```

## 相关文件

- `../schema.sql` - 建表SQL脚本
- `../data.sql` - 初始化数据脚本

## 目录说明

| 文件 | 内容 |
|------|------|
| `er-diagram.md` | 数据库实体关系图（ER图），包含所有实体及其关系 |
| `schema.md` | 数据库表结构设计，包含建表SQL语句 |
| `fields.md` | 所有表的字段详细说明，包括类型、约束、说明 |
| `initialization.md` | 数据初始化说明，包括状态码、初始化顺序等 |
